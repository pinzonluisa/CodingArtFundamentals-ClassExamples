# Coding Art Fundamentals: Class Examples

This repository holds the short p5.js examples we build together in class, Fall 2026. Each one demonstrates a single idea on its own, a variable, a conditional, whatever that week's topic is. This is not the assignment code, that stays in its own repository. Think of this one as a reference you can come back to and see exactly what we built in class, without digging through your own notes.

## Structure

Examples are organized by week, and each one is a plain `.js` file. Copy the code into your own p5.js template in VS Code to run it, there's no project folder to open here, just the sketch itself.

## What's Here So Far

Right now the repository covers Week 2: variables, if/else, and setup/draw, plus the loops example that opens Week 3. More weeks get added as we go.
